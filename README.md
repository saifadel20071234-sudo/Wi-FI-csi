### Wi-Fi Channel State Information (CSI) Real-Time Human Sensing & Thermal Spatial Tracking

## 📖 1. نبذة عن المشروع وفكرته (Project Overview)
يهدف المشروع إلى **استشعار وجود الإنسان، وتحديد موقعه المكاني، وتتبع حركته بدقة داخل الغرفة** دون الحاجة إلى:
* ❌ استخدام كاميرات (حماية تامة للخصوصية - Privacy-Preserving).
* ❌ ارتداء أي أجهزة أو مجسات على الجسم (Device-Free Sensing).
* ❌ وجود إضاءة (يعمل بكفاءة في الظلام التام وعبر العوائق والجدران).

يعتمد النظام على تحليل **معلومات حالة القناة اللاسلكية (Channel State Information - CSI)** بين بوردتي **ESP32**، حيث يتسبب وجود جسم الإنسان وحركته في تشتت وامتصاص إشارات الواي فاي عبر الترددات الحاملة الفرعية (64 Subcarriers)، فيتم التقاط تلك التشوهات وتحويلها عبر خوارزميات معالجة الإشارة والذكاء الاصطناعي إلى **خريطة حرارية تفاعلية حية** تُظهر موقع الشخص ومسار حركته بانسيابية تامة.

## 🛠️ 2. مخطط توصيل وتوزيع الهاردوير (Hardware Setup)

يتكون النظام من قطعتي **ESP32 (NodeMCU-32S / ESP32 Dev Module)**:

```
+---------------------------------------------------------------------------------+
|                                 الغرفة (5.0m × 5.0m)                            |
|                                                                                 |
|     [ 📡 ESP32 #1 - Transmitter ]                                               |
|       (موقع: X=2.5m, Y=0.45m)                                                   |
|       - موصل بشاحن 5V أو باوربانك                                               |
|       - يبث شبكة CSI_TX_NODE                                                    |
|                                                                                 |
|                        \      Fresnel Zone & RF Field      /                    |
|                         \                                 /                     |
|                          \         👤 جسم الإنسان         /                     |
|                           \     (Center / Left / Right)  /                      |
|                            \                            /                       |
|                             \                          /                        |
|                                                                                 |
|     [ 📥 ESP32 #2 - Receiver ]                                                  |
|       (موقع: X=2.5m, Y=4.55m)                                                   |
|       - موصل باللابتوب عبر USB                                                  |
|       - يستقبل الـ CSI وينقلها للداش بورد                                       |
+---------------------------------------------------------------------------------+
```

### 🔹 أ) البوردة الأولى: جهاز الإرسال (ESP32 #1 - Transmitter)
* **الموقع:** توضع في أحد أطراف الغرفة على ارتفاع (0.8 إلى 1.2 متر).
* **التوصيل:** لا تحتاج إلى الاتصال بالكمبيوتر؛ يكفي توصيلها بأي **شاحن هاتف محمول 5V** أو **باور بانك** أو منفذ USB.
* **الكود المبرمج عليها:** مبرمج مسبقاً بكود [`Transmitter_ESP32/Transmitter_ESP32.ino`](Transmitter_ESP32/Transmitter_ESP32.ino).
* **الحالة على جهازك:** متصلة حالياً على منفذ `COM8` ومبرمجة وجاهزة 100%.

### 🔹 ب) البوردة الثانية: جهاز الاستقبال (ESP32 #2 - Receiver)
* **الموقع:** توضع في الطرف المقابل للغرفة أمام جهاز الإرسال على بعد (2 إلى 4 أمتار).
* **التوصيل:** موصلة مباشرة بجهاز **اللابتوب** عن طريق كابل USB يدعم نقل البيانات.
* **الفيرموير:** مبرمجة بفيرموير احترافي مبني على **ESP-IDF** في [`firmware_receiver/`](firmware_receiver/).
* **الحالة على جهازك:** متصلة حالياً على منفذ `COM9` وتم حرق فيرموير الـ CSI واختباره بنجاح 100%.

## 📶 3. مواصفات الشبكة والاتصال اللاسلكي (Wi-Fi & RF Protocol)

لتحقيق أقصى استقرار وأعلى حساسية لالتقاط حركة الجسم، تم ضبط مواصفات التردد اللاسلكي بدقة:

| الخاصية (Parameter) | القيمة المضبوطة | الغرض التقني |
| :--- | :--- | :--- |
| **اسم الشبكة (SSID)** | `CSI_TX_NODE` | نقطة وصول لاسلكية مخصصة للرادار (SoftAP) |
| **كلمة المرور (Password)** | `12345678` | تشفير WPA2-PSK قياسي |
| **القناة الترددية (Channel)** | **Channel 6** (2437 MHz) | أهدأ تردد في نطاق 2.4GHz لتقليل تداخل الشبكات المجاورة |
| **المعيار اللاسلكي** | **IEEE 802.11n (HT20)** | استخدام تعديل OFDM بعرض نطاق 20 MHz |
| **الترددات الحاملة (Subcarriers)** | **64 Subcarriers** | استخراج السعة الطيفية (Amplitude) لكل الترددات (Data & Pilots) |
| **قدرة الإرسال (TX Power)** | **20 dBm (100 mW)** | أقصى قدرة إرسال للأنتينا لتشكيل منطقة فرينل قوية وواضحة |
| **معدل البث (Broadcast Rate)** | **20 حزمة/ثانية (UDP)** | إرسال حزمة كل 50 مللي ثانية لتتبع حركة الإنسان اللحظية بدون تأخير |
| **صيغة السيريال المنقولة للكمبيوتر** | `CSI_START,timestamp_ms,RSSI,64,amp0,...,amp63,CSI_END` | بروتوكول نصي يُحلل لحظياً |

### 🔹 أ) رادار الغرفة الحراري (Live Spatial Thermal Radar - 5m × 5m):
1. **مربع الغرفة الداكن (Pitch-Black Field):** يمثل أرضية الغرفة بمقياس رسم حقيقي (من 0 إلى 5 أمتار في الاتجاهين $X$ و $Y$).
2. **عقد الهاردوير (Hardware Nodes):**
   * **📡 TX (ESP32 #1):** مثلث سماوي في أسفل المنتصف عند الإحداثي `(2.5m, 0.45m)`.
   * **📥 RX (ESP32 #2):** مربع أخضر نيون في أعلى المنتصف عند الإحداثي `(2.5m, 4.55m)`.
3. **شعاع الرؤية المباشر ومنطقة فرينل (LOS Beam & Fresnel Zone):** خط متقطع يربط بين الجهازين مع بيضاوية منطقة فرينل الأولى التي تعبر عن مسار الإشارة اللاسلكية الأهم.
4. **الشكل الحراري للإنسان (Anisotropic Human Thermal Signature):**
   * **قلب أبيض متوهج (White-Hot Core):** يمثل مركز كتلة الرأس وأعلى الجسم (أعلى تركيز للحرارة والانعكاس).
   * **هالة إشعاعية متدرجة (Dual-Gaussian Body Mantle):** توزيع بيضاوي يحاكي أبعاد الجذع البشري (أحمر $\rightarrow$ برتقالي $\rightarrow$ أزرق سماوي).
   * **تذبذب فيزيائي حي (RF Micro-Fluctuations):** نبضات خفيفة تحاكي تنفس وحركة الدوبلر للشخص.
5. **الأثر الحراري المتلاشي (Thermal Wake Trail):**
   * عند تحركك من مكان لآخر، يترك النظام أثراً حرارياً ناعماً يتلاشى تدريجياً خلف مسار خطوتك، مما يوضح اتجاه وسرعة الحركة بانسيابية فائقة ودون أي تقطيع أو قفزات مفاجئة.
6. **مؤشر الهدف والإحداثيات اللحظية (Target Reticle & HUD):**
   * دائرة تصويب حمراء تحيط بموقعك مع صندوق بيانات يعرض:
     * الإحداثيات المترية الدقيقة: `TARGET: (X=2.50m, Y=2.50m)`.
     * سرعة الحركة اللحظية: `SPEED: 0.35 m/s`.

### 🔹 ب) لوحة القياسات الحية (Live RF Telemetry HUD):
1. **شعار الحالة المصنفة (Target State Badge):**
   * 🏠 `EMPTY ROOM` (الغرفة فارغة - الشاشة سوداء بالكامل).
   * 🧍 `PERSON IN CENTER` (الشخص واقف في منتصف الغرفة وقاطع لخط الإشارة).
   * 🧍 `PERSON ON RIGHT` (الشخص متواجد في الجانب الأيمن من الغرفة).
   * 🧍 `PERSON ON LEFT` (الشخص متواجد في الجانب الأيسر من الغرفة).
   * 🏃 `PERSON MOVING` (الشخص يتحرك ويمشي داخل الغرفة).
2. **مستوى قوة الإشارة (Live RSSI):** يوضح قوة استقبال الإشارة بالديسيبل ملي واط (dBm) لحظة بلحظة.
3. **نسبة ثقة الذكاء الاصطناعي (AI Confidence):** نسبة تأكد الموديل من القرار الحالي (تصل إلى 100%).
4. **عداد الحزم الخام (Packets Ingested):** إجمالي حزم الـ CSI التي تم استقبالها ومعالجتها منذ بدء الجلسة.
5. **مخطط أطياف الترددات (64 Subcarrier Spectrum):** رسم بياني شريطي فوري يعرض سعة كل تردد حامل (0 إلى 63) وتغيرها عند مرورك بين الأجهزة.

## ⚡ 5. خطوات تشغيل المشروع بالترتيب (Step-by-Step Execution)

### المتطلبات البرمجية

من جذر المشروع، ثبّت الحزم مرة واحدة:

```
python -m pip install -r requirements.txt
```

### حدود قياس مهمة

يوجد في النسخة الحالية رابط CSI واحد بين مرسل ومستقبل. لذلك تعرض الخريطة
تقديراً معايراً لمنطقة **يسار / وسط / يمين** وانتقالاً ناعماً عند الحركة؛ لا
يمكن لبوردتي ESP32 فقط إعطاء إحداثيات ثنائية الأبعاد دقيقة مثل الكاميرا. للحصول
على تموضع 2-D فعلي، أضف روابط CSI حول الغرفة وسجّل عينات معلّمة بإحداثيات `(x, y)`.

### 📌 الخطوة 1: تجهيز الأجهزة وتوزيعها
1. ضع **ESP32 #1 (Transmitter)** في طرف الغرفة وصلها بشاحن الهاتف أو الباوربانك (أو اتركها في اللابتوب على `COM8`).
2. ضع **ESP32 #2 (Receiver)** في الطرف المقابل وصلها بكابل الـ USB في اللابتوب (تأكد من تعريفها على `COM9`).

### 📌 الخطوة 2: التشغيل بضغطة زر واحدة (1-Click Run)
1. افتح مجلد المشروع:
   ```
   C:\Users\Adel\Desktop\Wi-Fi csi\
   ```
2. اضغط مرتين على ملف التشغيل الرئيسي:
   👉 **[`run_final.bat`](run_final.bat)**
3. سيقوم البرنامج بفحص المنافذ والموديل تلقائياً وعرض الشاشة الرئيسية:
   * اضغط **Enter** فقط لاختيار التشغيل المباشر `[1]`.
   *(إذا أردت إعادة حرق الفيرموير مستقبلاً في أي وقت، يمكنك اختيار `[2]`)*.

### 📌 الخطوة 3: التتبع والمراقبة الحية
1. ستفتح صفحة الداش بورد في متصفحك تلقائياً على الرابط: `http://localhost:8501`.
2. ستجد منفذ البوردة (`COM9`) محدداً مسبقاً في القائمة الجانبية.
3. اضغط على الزر الأخضر:
   **`🚀 CONNECT & START LIVE TRACKING`**
4. ابدأ بالتحرك في الغرفة:
   * قف في المنتصف $\rightarrow$ تظهر الهالة الحرارية المتوهجة في المركز.
   * تحرك لليمين $\rightarrow$ تنزلق الهالة بانسيابية للجهة اليمنى مع ترك أثر حراري.
   * تحرك لليسار $\rightarrow$ تنتقل الهالة إلى اليسار بسلاسة.
   * امشِ بين المناطق $\rightarrow$ يتحول التصنيف إلى `PERSON MOVING` وتتحرك الهالة حسب بصمة CSI المعايرة، من دون مسار دائري مصطنع.
   * غادر الغرفة $\rightarrow$ تتلاشى الهالة تدريجياً لتعود الشاشة سوداء بالكامل `EMPTY ROOM`.

## 🔄 7. إعادة جمع البيانات وتدريب النموذج

نفّذ الأوامر من جذر المشروع. الحفظ والمعالجة لا يعتمدان على مكان فتح الطرفية:

```
python firmware_receiver/collect_data.py --port COM9
python processing/signal_processor.py
python ml/ml_model.py
```

جامع البيانات يحفظ التسجيلات الجديدة في `data/raw`، والمعالج يحدّث
`data/csi_features.csv` والرسوم في `results`، ثم ينسخ التدريب ملفات النموذج إلى
`dashboard` تلقائياً. لا تعتبر دقة التقسيم العشوائي وحدها دقة ميدانية؛ اجمع جلسات
مستقلة لكل منطقة ثم اختبر في جلسة أو غرفة لم تدخل التدريب.

## 👨‍💻 8. فريق العمل (Project Team Roles)

* **عضو 2 (Receiver Lead):** برمجة فيرموير استخراج الـ CSI من الـ ESP32.
* **عضو 3 (DSP Lead):** تنقية الإشارات وفلترة الضوضاء واستخراج الخصائص الفيزيائية والطيفية.
* **عضو 4 (AI/ML Lead):** تدريب وتقييم نماذج تعلم الآلة (Random Forest Classifier).
* **عضو 5 (Visualization Lead):** تصميم وبناء محرك الرادار الحراري والداش بورد التفاعلية.
